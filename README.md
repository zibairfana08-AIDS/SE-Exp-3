# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
To design and develop a Railway Management System using UML diagrams to represent the system's structure, functionality, and interactions between passengers, railway staff, and administrators.

# SRS (Procedure):

Identify the requirements and objectives of the Railway Management System.

Identify the main actors, such as Passenger, Admin, and Railway Staff.

Prepare the Use Case Diagram to represent the functionalities of the system.

Draw the Class Diagram with suitable classes, attributes, methods, and relationships.

Draw the Sequence Diagram to represent interactions between objects.

Draw the Activity Diagram to illustrate the workflow of ticket booking and cancellation.

Draw the Communication Diagram to show interactions between objects.

Draw the Package Diagram to represent the organization of system modules.

Verify all diagrams based on the system requirements.
